How To use

  1. Subjects cannot be added from the archive, if you want to add or delte them, click here.
  2. Once added you can click the x button on the top-right and now you can switch between the preferred subject.
  3. Once a subject has been selected, you can only view it's archived notes. To view other notes return to the main page
  4. You can rename, delete, recover or expand(to show line breaks) the content of each note by clicking on its respective button.
