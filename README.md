Tinkernote is a web-app designed to make note-taking easier and more organized.

How to use:
Click on the edit subject button and add a new subject/topic(note: only letters, numbers and hyphen are valid characters).
Once added you can click the x button on the top-right and now you can switch between the preferred subject.
Once a subject has been selected, add a note by filling in the text box with the content you want as the first note and then click on the add note button.
You can rename, delete or expand(to show line breaks) the content of each note by clicking on its respective button.
All your data is saved in local storage.
