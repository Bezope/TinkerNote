How To use

  1. Click on the edit subject button and add a new subject/topic(note: only letters, numbers and hyphen are valid characters).
  2. Once added you can click the x button on the top-right and now you can switch between the preferred subject.
  3. Once a subject has been selected, add a note by filling in the text box with the content you want as the first note and then click on the add note button.
  4. You can rename, delete or expand(to show line breaks) the content of each note by clicking on its respective button.
  5. Once a note has been archived, it can only be viewed in the archive, it will not be deleted unless you want it to.
  6. If a subject is deleted, it's notes(INCLUDING those in archive) are permanently deleted and cannt be recoverd.
